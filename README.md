# 🚀 SaikatOS // AI Playground

> An interactive dual-theme Web Operating System and developer portfolio showcasing AI/ML projects, computer vision applications, competitive hackathons, and retro arcade mini-games.

---

## 🌟 Features

- **Dual OS Aesthetic**:
  - **Futuristic Stark AI HUD**: Sci-Fi neon glassmorphism inspired by Tony Stark's J.A.R.V.I.S interface with rotating telemetry HUD rings.
  - **90s Retro Desktop**: Nostalgic beveled Windows 95 / Classic OS interface with custom desktop icons and taskbar.
- **Audio Synthesizer Engine**: Integrated **Tone.js** synth triggering authentic retro clicks, HUD frequency bursts, and game chimes.
- **Interactive Terminal (`Terminal.sh`)**:
  - Run terminal commands: `help`, `about`, `skills`, `projects`, `hackathons`, `gaming`, `matrix`, `theme retro`, `theme hud`, `clear`.
  - Clickable quick-exec command chips for fast navigation.
- **Projects Lab**:
  - **LipRead Live**: Real-time silent speech recognition system using MediaPipe mesh landmark extraction and ML classification.
  - **ChessMind AI**: Interactive chess tactical learning web application with heuristic move analysis.
  - **Android Task Manager**: Cloud-synchronized task manager built with Firebase SDK & Android Studio.
- **Hackathon Trophy Room**:
  - *InnoFusion 3.0* (Team The Trinity)
  - *HackNex Season 2* (Team NODVEX)
  - *C-DAC Hackathons*
  - *Build with AI Bootcamp*
- **Cyber Snake Arcade (`Arcade.rom`)**:
  - Retro snake mini-game with score tracking, high-score memory, keyboard support (Arrow keys / WASD), and on-screen touch D-Pad.
- **Visual FX & Customization**:
  - CRT monitor scanline simulator.
  - Matrix digital rain background toggle.
  - 4 desktop wallpapers: Stark Radial, Cyberpunk Grid, Classic 1995 Teal, 90s Sunset Synth.

---

## 💻 Tech Stack

- **HTML5 & Vanilla JavaScript**: Core logic, window manager, state machine, and canvas game loops.
- **Tailwind CSS**: Modern utility styling and responsive layouts.
- **Tone.js**: Web Audio API synthesizer for UI sound effects.
- **Font Awesome & Google Fonts**: *Orbitron*, *VT323*, *Share Tech Mono*, and *Inter*.

---

## 🚀 Live Preview / How to Run

Simply open `index.html` in any modern web browser or host it with **GitHub Pages**:

1. In your repository on GitHub, go to **Settings** > **Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**. Your portfolio OS will be live instantly!
